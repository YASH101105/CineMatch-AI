# Code of Conduct

We welcome contributors of all experience levels and backgrounds. Communicate respectfully, give constructive feedback, respect privacy, and focus on the technical merits of changes.

Harassment, discrimination, threats, personal attacks, unwanted sexual attention, and disclosure of private information without consent are unacceptable.

## Reporting and enforcement

Report concerns privately to the repository maintainer using a private contact method listed on their GitHub profile, if available. Do not publish sensitive details in issues. If no private method is available, use GitHub's reporting tools for platform abuse.

The maintainer will review reports fairly, protect confidentiality where possible, and may remove harmful content, warn participants, or restrict participation proportionately. Retaliation against reporters is not acceptable.

This applies to repository discussions, issues, pull requests and project-related interactions.
